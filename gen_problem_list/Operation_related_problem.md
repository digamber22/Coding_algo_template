## Notes & tips
- For bitwise AND/OR, remember the per-right-index set trick: the number of possible AND/OR values ending at i is limited by bit width (so merging sets is efficient).
- For GCD problems, maintain set of gcds for subarrays ending at i — it stays small (O(log maxA)).
- For sliding window with negatives allowed, two pointers don't work — use prefix sums + data structures.
- Spend ~30–60 minutes on editorial reading after implementing a solution.
